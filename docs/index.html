INSTALL ON WINDOWS

  1. Click Download for Windows and save the zip (about 115 MB).
  2. Right-click the zip, choose Extract All, then open the folder.
  3. Double-click Install.bat. It adds Grave Suite to your Start menu and desktop.
  4. If Windows shows "Windows protected your PC", click More info, then Run anyway (the app is not code-signed).
